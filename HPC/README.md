## Overview

This repository contains code, cluster scripts, simulation outputs, logs, and figures produced for the High Performance Computing (HPC) Programming Exercises (17–21 Nov 2025) led by Dr James Rosindell.

The project implements:

* Stochastic demographic population models
* Individual-based neutral ecological simulations
* Large-scale parallel simulations on Imperial's CX3 HPC cluster
* Post-processing and visualisation of cluster outputs
* Challenge questions including equilibrium analysis and coalescence simulations

All simulations were executed using PBS array jobs on the CX3 cluster.

## Code

The `Code/` directory contains all source files required to reproduce the simulations.

Key files:

* `yy3324_HPC_2025_main.R`
  Main script containing all functions for the coursework questions and analyses.

* `yy3324_HPC_2025_demographic_cluster.R`
  Script executed on the cluster to run stochastic demographic simulations.

* `yy3324_HPC_2025_neutral_cluster.R`
  Script executed on the cluster to run neutral theory simulations.

* `Demographic.R`
  Provided model implementation for stochastic demographic processes.

* `run_demographic.pbs`
  PBS script for submitting demographic array jobs.

* `run_neutral.pbs`
  PBS script for submitting neutral model array jobs.

## Running the Simulations

### On the HPC Cluster (CX3)

Simulations were executed using PBS array jobs:

```
qsub run_demographic.pbs
qsub run_neutral.pbs
```

Each submission launched 100 parallel tasks, each producing a separate `.rda` output file.

---

### Local Analysis

After downloading cluster outputs, analyses and figures were produced locally using:

```
source("Code/yy3324_HPC_2025_main.R")
```

Individual question functions can then be called, for example:

```
question_5()
question_6()
Challenge_A()
Challenge_E()
```

## Notes on Reproducibility

* Relative paths are used throughout to ensure portability across machines.
* The working directory is assumed to be the project root.
* Random seeds are controlled within cluster scripts using the PBS array index.
* No absolute file paths are used.
