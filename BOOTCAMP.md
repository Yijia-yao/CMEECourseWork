# Computing Bootcamp index

The weekly folders are course exercises used to build working fluency in Bash, Git, Python and R. They are retained in their original teaching structure and are not presented as independent research projects.

| Folder | Main focus | Representative files |
| --- | --- | --- |
| [`week1/`](week1/) | Unix shell, file operations, introductory scripting and Git | `CountLines.sh`, `csvtospace.sh`, `tiff2png.sh`, `variables.sh` |
| [`week2/`](week2/) | Python control flow, functions, data structures and sequence exercises | `cfexercises1.py`, `lc1.py`, `dictionary.py`, `align_seqs.py` |
| [`week3/`](week3/) | R fundamentals, vectorisation, file I/O and population simulation | `Vectorize1.R`, `TreeHeight.R`, `Ricker.R`, `basic_io.R` |
| [`week4/`](week4/) | R data wrangling, plotting, regression and permutation tests | `DataWrang.R`, `PP_Regress.R`, `Florida.R`, `preallocate.R` |
| [`week5/`](week5/) | Linear models and statistical exercises with ecological datasets | `SwS01.R`–`SwS13.R` |
| [`week6/`](week6/) | Generalised linear models and diagnostics | `GLMs.ho1.R`–`GLMs.ho6.R` |
| [`Week16--Math/`](Week16--Math/) | Later mathematical-programming exercise | `0112.ipynb` |

## How to read this material

- `code/` or `Code/` contains scripts written or completed during exercises.
- `data/` contains supplied teaching datasets.
- `results/` contains generated outputs retained for traceability.
- `lecture/` and `handout/` contain supplied teaching material where present.

The strongest portfolio examples are the standalone [Computing MiniProject](MiniProject/) and [HPC Programming](HPC/) sections. The weekly folders show progression and breadth rather than polished research software.
